 🍔 Food Delivery Analytics

📌 Project Overview

Food Delivery Analytics is a data analysis and visualization project focused on understanding food delivery performance, delivery time, traffic conditions, weather impact, and delivery partner performance.

The project uses Python, MySQL, and Power BI to analyze delivery data and present meaningful insights through an interactive dashboard.

🎯 Project Objectives

- Analyze food delivery performance.
- Identify factors affecting delivery time.
- Understand the impact of weather and traffic conditions.
- Analyze delivery partner ratings.
- Explore order distribution by city category, vehicle type, and order type.
- Build an interactive Power BI dashboard.

🛠️ Technologies Used

 🔍 Project Workflow

1. **Data Collection:** Loaded the food delivery dataset.
2. **Data Cleaning:** Handled missing values, corrected data types, and standardized columns using Pandas.
3. **Exploratory Data Analysis:** Examined delivery times, weather, traffic, and partner ratings.
4. **SQL Analysis:** Used MySQL queries to analyze delivery performance and order distribution.
5. **Dashboard Development:** Created an interactive Power BI dashboard using KPI cards, charts, and date filters.

 📊 Key Analysis

- Total orders analyzed: 42,752 imported records
- Average delivery time: Approximately 26.37 minutes
- Average delivery partner rating: Approximately 4.63
- Average delivery partner age: Approximately 29.58 years
- City category-wise order distribution
- Weather-wise average delivery time
- Traffic-wise average delivery time
- Vehicle-wise and order-type distribution
- Delivery partner rating analysis
